# Repository Guidelines

## Project Structure & Module Organization

This is a Node.js crawler for public bidding notices from `yfbzb.com` (with multi-site support). Keep the runtime flow small and direct:

- `index.js`: entry point; parses `SITES` (comma-separated, fallback `SITE`, default `yfbzb`)/`TOTAL_PAGES`/`INTERVAL_MS`/`MIN_DELAY_S`/`MAX_DELAY_S`/`CRON_EXPR` plus per-site overrides `TOTAL_PAGES_<SITE>`/`CRON_<SITE>`/`SITES_CONFIG` JSON from env (argv fallback), validates each site and cron, starts `server.js` static server (`HTTP_PORT` 8080, `HTTP_ENABLED`, health on `/health`) and pre-generates `file/index.html` navigation (`generateNav()`), and runs a Node `setTimeout`-based scheduler — per-site `scheduleLoopForSite` concurrent via `Promise.all`, single run when `CRON_EXPR` empty, daily `m h * * *` otherwise (per-site `CRON_<SITE>` independent), refreshes navigation after each `generateReport(site)`.
- `crawler.js`: fetching, HTML parsing, retry handling, deduplication, checkpoint/resume, graceful shutdown, and Excel output. Site-aware via pluggable strategy (`sites/<site>.js` hooks `buildUrl`/`parse`/`extractId`/`isBoundary`/`linkPrefix`/`parseTotalPages`/`batchSize`/`headers`/`proxy`/`requestDelay`/`fallbackOn405`, defaults in `sites/_base.js`): `file/<site>/`, `state-<site>.json`, `crawl({site,…})` / `crawlPage(pageNo, siteConfig, …)` (old `(baseUrl, urlSuffix)` signature kept for tests). 代理换 IP（`http-proxy-agent/https-proxy-agent`，`HTTP_PROXY/CEB_PROXY_URL/PROXY_CEB`，`NO_PROXY` 白名单，`proxy:false + httpAgent/httpsAgent` 注入 `axios`，双 405 快败 + easy_proxies 节点端口轮换换 IP）。It exports `crawl()`, `crawlPage()`, `backoffDelay()`, `readRecentIds()`, `fileDir()`, `stateFile()`.
- `log.js`: dual-channel logging (console Chinese + structured JSONL) shared by `crawler.js` and `report.js`; per-site `logs/<site>/crawler-YYYY-MM-DD.jsonl`, `log(msg,{site})` must pass `site` explicitly under concurrent multi-site (global `currentSite`/`setSite()` retained for compat but races), `logDir(site)` and `pruneOldLogs(site)` per-site.
- `report.js`: reporting and Excel analysis helpers; `scanFiles(site)` / `generateReport(site)` per site（索引页内联跨全部日期最新 `LATEST_PREVIEW_COUNT`=10 条预览（每行带日期）+ 日期索引，明细落 `<date>.html`）, `generateAllReports(sites)` concurrent via `Promise.all`, plus total navigation `collectSiteStats(site)` / `buildNavHtml(sitesData)` / `generateNav(sites)` (dynamic `sites/*` discovery, `yfbzb`/`ceb` pinned, `demo` excluded, card CTA → `file/<site>/index.html` + secondary `↗ 原站` → `originUrl`, `NAV_CSS`, `file/index.html` + `file/tokens.css`, placeholder per-site report if missing).
- `server.js`: zero-dependency static server hosting `file/` on `HTTP_PORT` (default 8080, `HTTP_ENABLED` toggle, `EXPOSE 8080`); `createServer()`/`startServer()`/`buildHealthPayload()`; routing `/` → `file/index.html` (nav), `/<site>/` → `file/<site>/index.html`, traversal-safe `safeJoin`, correct MIME, `HEAD` support; advanced `GET /health`/`/healthz`/`/api/health` → `{status,timestamp,uptime,navExists,navGeneratedAt,totals,sites[]}` with `no-store`, used by compose `healthcheck` (`node require('http').get`).
- `sites/`: site registry. `sites/yfbzb.js` is live (`axios`, with `linkPrefix` + `displayName`/`description`/`originUrl`), `sites/ceb.js` is live（`axios` + 代理换 IP，custom `buildUrl`/`parse`/`extractId`/`isBoundary`, `batchSize:1`, `requestDelay 2500-5500ms`, `headers` + `displayName`/`originUrl`, `fallbackOn405` + 双 405 熔断，代理经 `HTTP_PROXY/CEB_PROXY_URL` 注入）, `sites/demo.js` is an example template showing strategy hooks, `sites/site2.js` is a skeleton placeholder, `sites/_base.js` is the default strategy base, `sites/index.js` exposes `getSiteConfig(site)`/`getSiteConfigs(sites)`/`listSites()`/`listEnabledSites()`/`normalizeSites()`/`parseSitesList()`.
- `test/`: zero-dependency Node test suites and fixtures. `test/run.js` loads every `*.test.js`; the current set includes `easy_proxies.test.js` for the provider contract and `dual405.test.js` for current-page retry/gate abort behavior.
- `file/`: generated Excel output, partitioned by site then publish date (for example, `file/yfbzb/2026-08-14.xlsx`) plus per-site reports `file/<site>/index.html`/`tokens.css`/`<date>.html` and total navigation `file/index.html`/`file/tokens.css` (hosted by `server.js` on `HTTP_PORT` 8080, `GET /health` probe). Do not hand-edit generated files. Legacy flat `file/*.xlsx` is kept without migration.
- `logs/`: generated JSONL logs, per-site per-day (`logs/yfbzb/crawler-YYYY-MM-DD.jsonl`). Created at runtime; pruned on a 30-day window by `report.js`.
- `state-<site>.json`: transient per-site checkpoint (cwd-relative); written each batch, deleted on clean finish. Per-site, no collision under concurrent multi-site (one container multiple sites).
- `server.js`: static server for `file/` (see above), started by `index.js`, fronted by external reverse proxy for domain.
- `Dockerfile` / `.dockerignore` / `docker-compose.yml`: container image (`node:20-alpine` + `tzdata` + `ca-certificates` + `TZ=Asia/Shanghai` + `EXPOSE 8080`, 轻量无 `chromium`) and dual-service compose `easy_proxies`（默认启用，管理 API `9091`，multi-port `24000-24200`，`crawler` 以 `service_started` 依赖）+ `crawler` with `SITES=yfbzb,ceb` concurrent (bind mount `file/`/`logs/`, `ports: "${HTTP_PORT:-8080}:${HTTP_PORT:-8080}"`, `healthcheck` on `/health`, `mem_limit 400m`/`cpus 0.5`, per-site `CRON_<SITE>`/`TOTAL_PAGES_<SITE>` env, `HTTP_PORT`/`HTTP_ENABLED`/`CEB_PROXY_URL` 经 `easy_proxies:24000` 注入；启动与每轮抓取开始时按 `EASY_PROXIES_REFRESH_COOLDOWN=600s` 限频调用 `POST /api/subscription/refresh`，空池或管理面不可达时安全降级). `easy_proxies/config.yaml` 由示例文件复制后本地填写，不入仓库。
- `.github/workflows/docker-build.yml`: GHCR build & push on `push main` / `tag v*` / `workflow_dispatch` (`npm test` gate, `gha` cache, `linux/amd64,linux/arm64`).
- `page_content.html`: yfbzb 离线样页快照，用于离线校验 Cheerio 选择器；ceb 无随仓样页（`.dockerignore` 的 `page_content*.html` 排除于镜像），回归以线上解析为准。
- `docs/agents/`: local workflow and domain notes.
- `jsreverse-yidun/` (gitignored): ceb→ctbpsp 迁移的逆向成果归档（易盾协议实现/取证/可切回的 `ceb.js`+`crawler.js`），迁移已于 2026-08-25 终止，结论见 `docs/progress-ceb-ctbpsp.md`；勿重复攻坚 ctbpsp 求解器（卡点是服务端风控策略）。
- `CLAUDE.md`: repository-specific agent instructions; consult it before changing crawler behavior.
- `TODOLIST.md`: easy_proxies 接入清单；记录已完成的契约/测试工作和仍需 Docker 实机完成的验证。

## Build, Test, and Development Commands

- `npm install`: install declared dependencies.
- `node index.js [pages] [intervalMs] [minDelaySec] [maxDelaySec]`: run the crawler. Example: `node index.js 10 5000 0 0`.
- `SITES=yfbzb,ceb TOTAL_PAGES=100 INTERVAL_MS=5000 MIN_DELAY_S=0 MAX_DELAY_S=300 CRON_EXPR="0 2 * * *" node index.js`: env overrides argv; `SITES` comma-separated concurrent, `SITE` single-site compat, `CRON_<SITE>`/`TOTAL_PAGES_<SITE>` per-site override or `SITES_CONFIG` JSON; `CRON_EXPR` empty = single run + keepalive, `m h * * *` = daily schedule (`nextCronDelay`), per-site independent.
- `node test/run.js` or `npm test`: run the complete test suite (zero-dep `assert`, `freshCrawler()` + `withTempCwd()` isolation; current run contains 8 suites).
- `Copy-Item easy_proxies/config.yaml.example easy_proxies/config.yaml`: prepare the local proxy-sidecar config before Compose; fill `subscriptions` or `nodes_file`, and keep the resulting file untracked.
- `docker build -t crawler:local .` / `docker compose up -d --build` / `docker compose logs -f crawler` / `curl http://127.0.0.1:8080/health | jq` / `docker compose down`: container run (`TZ=Asia/Shanghai`, bind mount `file/`/`logs/`, `SITES` multi-site, `HTTP_PORT` 8080 hosted nav at `/` + per-site reports at `/<site>/` + advanced probe at `/health`).

There is no configured build, formatter, or linter. Use a supported current Node.js release (Node 18+ is the project baseline).

## Coding Style & Naming Conventions

Use CommonJS (`require`/`module.exports`), 2-space indentation, semicolons, and `camelCase` for variables and functions. Name tests as `test/<behavior>.test.js`. Preserve Chinese for CLI usage and runtime log messages.

Keep `crawler.js` behavior explicit: 403 (or site `isBoundary`) represents the site end-of-data boundary and must not be retried as a network failure; `isBoundary`/`buildUrl`/`parse`/`extractId`/`parseTotalPages` are pluggable per-site via `sites/<site>.js` (`sites/_base.js` defaults). 代理经 `HTTP_PROXY/CEB_PROXY_URL/PROXY_CEB` + `NO_PROXY` 注入 `axios`（`proxy:false + httpAgent/httpsAgent`，`http-proxy-agent/https-proxy-agent`，日志脱敏）；`easy_proxies` provider 通过 `/api/nodes` 过滤健康节点并按独立端口轮换，`POST /api/subscription/refresh` 仅成功后记冷却。Deduplication is keyed by `id` (via `extractId`); preserve both in-memory filtering and merge-time protection when changing output logic. The checkpoint (`state-<site>.json` via `stateFile(site)`) is deleted on clean finish. Retry backoff is exponential + full jitter via `backoffDelay()` (base 2s, cap 60s); keep it pure. `GET 405 → POST` 降级与双 405 快败对 `axios` 全链路有效；双 405 单页即尝试换端口且成功换点重置连续 405 计数；第一页探针一路换点直到成功或节点池轮尽，轮尽返回 `gateAbort` 由 `crawl()` 取消本次抓取；换点后只 destroy 本站 keepAlive Agent，网络级连败达 `NET_FAIL_SWITCH_THRESHOLD`=2 换 IP、换后仍败至 `NET_FAIL_BREAK_THRESHOLD`=6 熔断。Per-site `batchSize`/`failureThreshold`/`timeout`/`headers`/`proxy`/`requestDelay` override the `BATCH_SIZE`/`FAILURE_STOP_THRESHOLD`/`REQUEST_TIMEOUT`/`USER_AGENT` globals.

## Testing Guidelines

Tests use Node's built-in assertion facilities and mock `axios` through `require.cache`. Use `freshCrawler()` from `test/helper.js` when a test needs a new mocked crawler module, and `withTempCwd()` for tests that write Excel files or logs (it isolates `file/<site>/`, `logs/<site>/`, and `state-<site>.json` to a temp dir via cwd-relative `fileDir(site)`/`logDir(site)`/`stateFile(site)`). Cover parsing/deduplication, 403 boundaries, retry backoff, file merging, crawl termination (incl. real-total-pages cap narrowing), and easy_proxies node/auth/refresh/rotation behavior as applicable. Run `node test/run.js` (or `npm test`) before submitting changes. `SITE=site2` fails fast (placeholder); `SITES=yfbzb,ceb` with mock should verify `file/<site>/`/`logs/<site>/` isolation. When mocking provider calls, install the axios mock before loading `crawler.js` or `sites/_easy_proxies.js`.

## Commit & Pull Request Guidelines

Follow Conventional Commit prefixes with a concise Chinese summary, for example: `fix: 修正 403 边界处理`. Keep commits focused. Pull requests should explain the behavioral change, list verification commands and results, link the relevant issue when available, and include sample output or screenshots only when they clarify changed user-visible behavior.

## Security & Configuration

Respect the target site crawler policy and rate limits. Query filters, URLs, and selectors are site-specific per `sites/<site>.js` and consumed by `crawler.js`; 全站 `axios`，`ceb` 固定 IP 被 WAF 拦时经 `CEB_PROXY_URL` 使用 `easy_proxies` multi-port 换 IP（默认 `http://easy_proxies:24000`，管理 API `9091`，订阅刷新 `POST /api/subscription/refresh`，失败安全降级，不记录订阅地址或节点 IP）。Review `sites/index.js` registry and `sites/_base.js` defaults before changing crawl scope. One container runs multiple sites concurrently (`SITES=yfbzb,ceb` via `Promise.all`, per-site `CRON_<SITE>` independent, `yfbzb` 并发/`ceb` 串行+熔断); `site2` is a skeleton and must fail fast (skipped with warn in multi-site mode). Do not commit credentials or generated output (`file/`/`logs/`/`state-<site>.json`). `TZ=Asia/Shanghai` is required in image/compose — otherwise date partitioning drifts.
